## 🌟 معرفی پروژه

**گریفین کش (Griffin Cash)** یک اپلیکیشن وب حرفه‌ای برای مدیریت مالی شخصی و تجاری است که با تمرکز بر **حریم خصوصی کامل**، سرعت بالا و عدم وابستگی به سرویس‌های ابری طراحی شده است. تمامی اطلاعات مالی شما به صورت محلی در پایگاه داده SQLite روی سیستم‌عامل ذخیره می‌شود و رابط کاربری آن با پشتیبانی کامل از راست‌چین (RTL) و تایپوگرافی فارسی بهینه‌سازی شده است.

---

## ✨ قابلیت‌ها و امکانات کلیدی

### ۱. پایگاه داده محلی و ساختار رابطه‌ای (SQLite)
- ذخیره‌سازی امن اطلاعات در پوشه محلی برنامه (`userData`).
- جدول‌های رابطه‌ای بهینه‌شده برای ورک‌اسپیس‌ها، حساب‌های بانکی، مخاطبین و تراکنش‌ها.
- محاسبه خودکار و آنی موجودی هر حساب بانکی بر اساس موجودی اولیه و مجموع ورودی/خروجی‌ها.

### ۲. مدیریت فضاهای کاری مستقل (Workspaces)
- امکان ایجاد، ویرایش و سوییچ سریع بین چندین ورک‌اسپیس (مانند: *«حساب شخصی و منزل»، «پروژه‌های فریلنسری»، «کسب‌وکار و مغازه»* و...).
- **ایزوله‌سازی کامل** حساب‌های بانکی، مخاطبین، تراکنش‌ها و گزارش‌ها برای هر ورک‌اسپیس به‌صورت مستقل.

### ۳. حساب‌های بانکی و کارت‌ها (Accounts)
- ثبت و مدیریت کارت‌ها و حساب‌ها (نام بانک، شماره کارت ۱۶ رقمی، شماره شبا، شماره حساب، نام دارنده، موجودی اولیه و رنگ اختصاصی کارت).
- کارت‌های بانکی تعاملی با قابلیت کپی سریع شماره کارت و شبا با یک کلیک.
- پشتیبانی از انتقال وجه داخلی بین حساب‌ها (Transfer).

### ۴. دفتر مخاطبین و اصناف (Contacts & Ledgers)
- تفکیک مخاطبین به دو دسته:
  - **اشخاص حقیقی:** دوستان، خانواده، همکاران.
  - **فروشگاه‌ها / اصناف:** سوپرمارکت، کارفرما، شرکت‌های خدماتی.
- محاسبه خودکار تراز مالی با هر طرف‌حساب:
  - میزان طلب ما از او (قرض داده شده / Loan)
  - میزان بدهی ما به او (قرض گرفته شده / Debt)
  - تراز نهایی (بی‌حساب، طلبکار یا بدهکار)
  - مجموع خریدهای انجام‌شده از فروشگاه‌ها یا دریافتی‌ها از کارفرما.
- **صورت‌حساب اختصاصی (Statement Ledger)** برای هر مخاطب به همراه قابلیت ثبت سریع تراکنش.

### ۵. انواع تراکنش‌های مالی (Transactions)
- **واریز / درآمد (Income):** ثبت حقوق، پاداش و درآمدهای جانبی با اتصال به حساب و مخاطب.
- **پرداخت / هزینه (Expense):** مدیریت هزینه‌های روزمره، خواربار، اجاره، قبوض و...
- **قرض دادم (Loan):** ثبت مبالغ امانی داده‌شده به دیگران.
- **قرض گرفتم (Debt):** ثبت بدهی‌ها و وام‌ها تا زمان تسویه.
- **انتقال بین حساب‌ها (Transfer):** جابجایی وجه بین کارت‌های شخصی.
- فرمت‌بندی هوشمند مبالغ (تومان) در لحظه ورود، ثبت شماره پیگیری بانکی و پشتیبانی کامل از تاریخ شمسی.

### ۶. نمودارها و گزارش‌های تحلیلی پیشرفته (Analytics)
- **مقایسه ماهانه نقدینگی:** نمودار میله‌ای و خطی مقایسه درآمد، مخارج و تراز خالص نقدینگی در ۱۲ ماه گذشته به همراه جدول ریز عملکرد.
- **مقایسه سالانه وضعیت نقدینگی:** مقایسه کلان درآمدها، مخارج، پس‌انداز ناخالص و نرخ پس‌انداز سالانه.
- **گزارش‌های هفتگی:** مقایسه ۴ هفته اخیر به همراه میانگین مخارج روزانه و توزیع روز به روز هزینه‌ها (از شنبه تا جمعه).

## 🛠️ تکنولوژی‌های استفاده شده

- **فرانت‌اند:** React, TypeScript, Tailwind CSS, Phosphor Icons
- **بک‌اند / دسکتاپ:** Electron, Node.js
- **پایگاه داده:** `better-sqlite3` (درایور بسیار سریع و همگام SQLite)
- **اعتبارسنجی:** Zod (جهت تایپ‌سیف بودن ارتباطات IPC)
- **ابزار ساخت:** Vite, electron-vite

## 🚀 راهنمای نصب و راه‌اندازی (Development)

### پیش‌نیازها
مطمئن شوید که Node.js و پکیج‌منیجر `pnpm` روی سیستم شما نصب شده‌اند.

### مراحل نصب:

1. کلون کردن مخزن:
   ```bash
   git clone [https://github.com/yourusername/griffin-cash.git](https://github.com/yourusername/griffin-cash.git)
   cd griffin-cash

```

2. نصب وابستگی‌ها:
```bash
pnpm install

```


3. بازسازی ماژول بومی SQLite برای محیط الکترون:
```bash
npx electron-rebuild -f -w better-sqlite3

```


4. اجرای برنامه در حالت توسعه (Development):
```bash
pnpm run dev

```
